# إعادة توليد دليلَي التطبيق (الموظف، الإدارة)

الدليلان مبنيان من لقطات حقيقية لنسخة الويب المنشورة من التطبيق
(`https://muneerradwan-manager.github.io/sdhu_operations_project/`) عبر Playwright ومتصفح Chrome المثبت على الجهاز،
وبالمنسّق نفسه الذي بُنيت به أدلة `sdhu_testing_website` (`build_docx.py` و`site_link.py` منقولان من هناك ومعدَّلان).

## قبل التشغيل
- بيئة بايثون محلية: `python3 -m venv .venv && .venv/bin/pip install python-docx playwright pillow pymupdf`
- ملف `.env` في جذر المشروع (يُقرأ منه رابط Supabase ومفتاحه العام).
- حساب يملك كل الصلاحيات في `SDHU Projects/keys/guide-admin.env` — **خارج المستودع**:
  ```
  ADMIN_EMAIL=...
  ADMIN_PASSWORD=...
  ```

## التشغيل
1. الالتقاط (كلٌّ يبدأ مجلده من جديد):
   - `.venv/bin/python cap_employee.py` ← `employee/` (شاشة هاتف 412×915)
   - `.venv/bin/python cap_management.py` ← `management/` (شاشة حاسوب 1280×800)
2. التحويل إلى JPG: `.venv/bin/python to_jpg.py employee` و`to_jpg.py management`
3. البناء:
   - `.venv/bin/python build_docx.py employee_content employee "../دليل-الموظف-لاستخدام-التطبيق/دليل-الموظف-لاستخدام-التطبيق.docx"`
   - `.venv/bin/python build_docx.py management_content management "../دليل-الإدارة-لاستخدام-التطبيق/دليل-الإدارة-لاستخدام-التطبيق.docx"`
4. الفهرس يُحدَّث تلقائياً عند فتح الملف في Word. ولـ PDF: من Word (أو Pages على الماك) ← تصدير.

## ملاحظات
- **البيانات حقيقية والأسماء وهمية.** الالتقاط على قاعدة البيانات الحية. `anon.py` يعيد كتابة ردود Supabase داخل المتصفح قبل أن يرسمها التطبيق: كل اسم ورقم هاتف وبريد وصورة شخصية يُستبدل بنظير وهمي ثابت (الاسم نفسه يصير الاسم الوهمي نفسه في كل اللقطات). لا يُكتب في قاعدة البيانات شيء. وتُقرأ قائمة الأسماء مرة عند البدء، فيُستبدل الاسم حتى داخل نص حر (إشعار، سجل الأحداث).
  - كل لقطة تُفحص بعدها: إن بقي اسم حقيقي أو بريد على الشاشة يطبع السكربت `!! real data still on screen`، و`to_jpg.py` يموّه أي بريد ليس `@example.com`.
  - مدخلات الاختبار العبثية في البيانات الحية («srthsrth»…) تُستبدل بأمثلة عربية من قاموس `JUNK` في `anon.py`. وكل نص لاتيني صِرف يمرّ يُسجَّل في `<المجلد>/ascii_seen.txt`؛ أضف الجديد منه إلى `JUNK`.
  - `Anon` يدخل بحساب الأدمن ليقرأ الأسماء ثم يخرج بـ `scope=local` — الخروج الافتراضي (global) يُخرج الحساب من كل أجهزته.
- **لا يُضغط زر حفظ أو إرسال أو اعتماد أو حذف.** النماذج تُفتح وتُكتب لتظهر ثم تُغلق. أي لقطة تحتاج تنفيذاً فعلياً تُستأذن قبلها.
- Flutter يرسم على canvas؛ `Cap.open()` يشغّل الـ semantics فتصير كل تسمية عقدة `flt-semantics` لها صندوق حقيقي — بها يُضغط بالنص وتُرسم الإطارات الحمراء. والصفحة `dir=rtl` فيُزاح غطاء الـ semantics إلى اليمين؛ `semantics()` يثبّته LTR (لا يتغير بكسل لأن الغطاء غير مرئي).
- كل انتظار عبر `page.wait_for_timeout` لا `time.sleep`: في واجهة Playwright المتزامنة لا تُخدَم الطلبات المعترَضة (anon) إلا والسكربت داخل نداء Playwright.
- الخريطة التشغيلية في الشاشة الرئيسية عقدة semantics واحدة، فلا يُمرَّر إليها بالنص: المسافات مقيسة (الهاتف: المرحلة 3 على ~4350px، الحاسوب: المرحلة 2 على ~1700px).
- الضغط على «1448 هـ» في رأس القائمة يطويها لكل اللقطات بعدها؛ لذلك يُضغط على بطاقة الموسم نفسها.
- `state-*.json` (جلسات المتصفح) و`shots/` و`jpg/` لا تُرفع إلى المستودع.
